# Brain2 v2 Implementation Plan

> ⚠️ **STALE — DO NOT EXECUTE YET.** This plan predates several design changes now in the spec (2026-05-23): (1) **multi-wiki** — `wiki_id` threads through nearly every signature and storage moves to `BRAIN2_ROOT/wikis/<wiki_id>/`; (2) **auth boilerplate** — `UserProfile`/roles/`WikiMeta`/`authorize()` seam + `X-User-Id` hook + access-management ops; (3) **`LocalStore`** replaces `FileStore` — files for knowledge, **per-user SQLite `learning.db`** (concept_state + review_event with an indexed `due_at`) for review state, so `get_due_concepts` is an indexed query not a file scan; (4) **centralized user ownership root** `users/<user_id>/` with `export_user_data`/`delete_user_data`; (5) **pluggable cloud LLM** (`LLMClient` → Anthropic + Gemini, selected by `CLOUD_LLM_PROVIDER`). The plan will be **regenerated in one pass** from the updated spec ([2026-05-19-brain2-v2-design.md](../specs/2026-05-19-brain2-v2-design.md), §23 has the new 14-phase order) before implementation begins. Treat the sections below as reference only for pieces that didn't change (FSRS wrapper math, ingestion modules, sync/op logic, content/query/search prompts).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Brain2 — a personal knowledge engine that ingests anything you read or watch, compiles it into a living Obsidian wiki, breaks each page into atomic concepts, and teaches them back via spaced repetition. Expose every operation through a canonical REST API, wrap it with an MCP server for AI agents, and ship a no-LLM Telegram bot for hands-on testing.

**What we're building (capabilities):**
- **Ingest** URLs (video/article), PDFs, audio, and pasted text → transcribed, cleaned, filed.
- **Compile** a living wiki where each topic is one coherent page; wiki pages themselves are the topic registry (no taxonomy file); `/compile` keeps pages healthy and suggests merges.
- **Concepts**: each wiki page decomposes into atomic, testable propositions with stable IDs; incremental sync adds/refines/supersedes/retires/merges them as pages change, preserving review history.
- **Learn**: FSRS-scheduled spaced repetition with Nugget (first-time) and Chunk (consolidation) sessions; each session opens with a flowing reading, then dynamically generated Q-A cards.
- **Ask**: synthesize answers from concepts + wiki with citations; propose write-backs that enrich the wiki.
- **Three interfaces over one logic path**: REST (canonical) → MCP (thin agent wrapper) → Telegram bot (REST test client).

**Architecture:** Business modules hold all logic and take a `Store`. A handler layer (`handlers.py`, given a `BrainContext` = store + task runner) defines every operation once. FastAPI routes and MCP tools are thin adapters over those handlers — if REST passes, only adapter glue can break. Knowledge (wiki + concepts) is shared; learning state (FSRS, writebacks) is per-user, keyed on `user_id` (default `"self"`). All persistence flows through `Store` (`FileStore` now, `PostgresStore`-ready). Ingestion is async (ThreadPoolExecutor + persisted task tracker); everything else is synchronous. Two LLM tiers: Ollama local (classify/clean/lint), Claude cloud (sync diff, wiki merge, content gen, /ask). Two entrypoints: `brain2` (MCP/stdio), `brain2-api` (FastAPI/uvicorn). The Telegram bot lives in-repo and drives the REST API.

**Tech Stack:** Python 3.11+, `mcp[cli]`, `fastapi`, `uvicorn`, `httpx`, `python-telegram-bot`, `anthropic`, `requests` (Ollama HTTP), `py-fsrs`, `pydantic`, `pytest`, `pytest-asyncio`, `pytest-mock`, `yt-dlp`, `faster-whisper`, `trafilatura`, `pdfplumber`, `pytesseract`, `python-dotenv`. uv for env mgmt.

**Reference:** [docs/superpowers/specs/2026-05-19-brain2-v2-design.md](../specs/2026-05-19-brain2-v2-design.md)

"""Pydantic models for Brain2 data structures."""
from datetime import datetime
from typing import Any, Literal
from pydantic import BaseModel, Field


# --- Concepts (shared) ---

class Concept(BaseModel):
    id: str
    topic: str
    statement: str
    source_page: str
    related_ids: list[str] = Field(default_factory=list)
    created_at: datetime
    status: Literal["active", "superseded", "retired"] = "active"
    supersedes_id: str | None = None


class ConceptsFile(BaseModel):
    topic: str
    source_page_path: str
    wiki_content_hash: str = ""
    last_synced_at: datetime | None = None
    concepts: list[Concept] = Field(default_factory=list)


# --- Per-user learning state ---

class FSRSState(BaseModel):
    difficulty: float = 5.0
    stability: float = 0.0
    last_reviewed: datetime | None = None
    retrievability: float = 1.0


class ReviewEvent(BaseModel):
    ts: datetime
    rating: Literal[1, 2, 3, 4]


class UserConceptState(BaseModel):
    concept_id: str
    fsrs: FSRSState = Field(default_factory=FSRSState)
    review_history: list[ReviewEvent] = Field(default_factory=list)


class UserStateFile(BaseModel):
    user_id: str
    topic: str
    states: list[UserConceptState] = Field(default_factory=list)


# --- /ask writebacks (per-user) ---

class WritebackProposal(BaseModel):
    id: str
    user_id: str
    question: str
    answer: str
    citations: list[str]
    target_page: str
    sanitized_content: str
    created_at: datetime
    status: Literal["pending", "accepted", "rejected"] = "pending"


class WritebackProposalsFile(BaseModel):
    proposals: list[WritebackProposal] = Field(default_factory=list)


# --- Async tasks (per-user) ---

class Task(BaseModel):
    id: str
    user_id: str
    type: str
    input: dict[str, Any]
    status: Literal["pending", "running", "done", "failed", "cancelled"] = "pending"
    progress: str = ""
    result: dict[str, Any] | None = None
    error: str | None = None
    created_at: datetime
    updated_at: datetime
```

"""Store Protocol — the abstraction every Brain2 module talks to.
MVP: FileStore. Future: PostgresStore. Same interface."""
from typing import Protocol
from brain2.models import (
    ConceptsFile, UserStateFile, WritebackProposalsFile, Task,
)


class Store(Protocol):
    # --- Shared knowledge ---
    def list_topics(self) -> list[str]: ...

    def load_wiki_md(self, topic: str) -> str | None: ...
    def save_wiki_md(self, topic: str, content: str) -> None: ...

    def load_concepts_file(self, topic: str) -> ConceptsFile | None: ...
    def save_concepts_file(self, cf: ConceptsFile) -> None: ...

    def load_index(self) -> str: ...
    def save_index(self, content: str) -> None: ...

    def append_log(self, line: str) -> None: ...

    def wiki_md_hash(self, topic: str) -> str: ...

    # --- Raw sources ---
    def list_raw_files(self, topic: str) -> list[str]: ...
    def load_raw_file(self, topic: str, filename: str) -> str: ...
    def save_raw_file(self, topic: str, filename: str, content: str) -> None: ...
    def list_raw_topics(self) -> list[str]: ...
    def list_unprocessed_raw(self, topic: str) -> list[str]: ...

    # --- Per-user ---
    def load_user_state(self, user_id: str, topic: str) -> UserStateFile | None: ...
    def save_user_state(self, state: UserStateFile) -> None: ...
    def list_user_state_topics(self, user_id: str) -> list[str]: ...

    def load_writebacks(self, user_id: str) -> WritebackProposalsFile: ...
    def save_writebacks(self, user_id: str, f: WritebackProposalsFile) -> None: ...

    # --- Tasks ---
    def load_tasks(self) -> list[Task]: ...
    def save_tasks(self, tasks: list[Task]) -> None: ...
```

"""Concept ID generation: <topic>/<concept-slug>-<4charhash>."""
import hashlib
import re
from config import SLUG_STOP_WORDS, SLUG_MAX_LENGTH


def concept_slug(text: str) -> str:
    s = text.lower()
    s = re.sub(r"[^\w\s-]", " ", s)
    s = s.replace("-", " ")
    words = [w for w in s.split() if w and w not in SLUG_STOP_WORDS]
    slug = re.sub(r"-+", "-", "-".join(words)).strip("-")
    if len(slug) > SLUG_MAX_LENGTH:
        slug = slug[:SLUG_MAX_LENGTH].rstrip("-")
    return slug


def content_hash(statement: str) -> str:
    return hashlib.sha256(statement.encode("utf-8")).hexdigest()[:4]


def concept_id(topic: str, statement: str) -> str:
    return f"{topic}/{concept_slug(statement)}-{content_hash(statement)}"
```

"""FileStore — disk-backed implementation of the Store Protocol."""
import hashlib
import json
import os
import tempfile
from pathlib import Path

import config
from brain2.models import (
    ConceptsFile, UserStateFile, WritebackProposalsFile, Task,
)


def _atomic_write_text(path: Path, content: str) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=".tmp-")
    try:
        with os.fdopen(fd, "w") as f:
            f.write(content)
        os.replace(tmp, path)
    except Exception:
        os.unlink(tmp)
        raise


class FileStore:
    # --- Shared wiki ---
    def list_topics(self) -> list[str]:
        if not config.WIKI_DIR.exists():
            return []
        out = []
        for d in config.WIKI_DIR.iterdir():
            if not d.is_dir() or d.name.startswith((".", "_")):
                continue
            if (d / f"{d.name}.md").exists():
                out.append(d.name)
        return sorted(out)

    def load_wiki_md(self, topic: str) -> str | None:
        p = config.WIKI_DIR / topic / f"{topic}.md"
        return p.read_text() if p.exists() else None

    def save_wiki_md(self, topic: str, content: str) -> None:
        _atomic_write_text(config.WIKI_DIR / topic / f"{topic}.md", content)

    def wiki_md_hash(self, topic: str) -> str:
        p = config.WIKI_DIR / topic / f"{topic}.md"
        return hashlib.sha256(p.read_bytes()).hexdigest()

    def load_concepts_file(self, topic: str) -> ConceptsFile | None:
        p = config.WIKI_DIR / topic / f"{topic}{config.CONCEPTS_FILENAME_SUFFIX}"
        if not p.exists():
            return None
        return ConceptsFile.model_validate_json(p.read_text())

    def save_concepts_file(self, cf: ConceptsFile) -> None:
        p = config.WIKI_DIR / cf.topic / f"{cf.topic}{config.CONCEPTS_FILENAME_SUFFIX}"
        _atomic_write_text(p, cf.model_dump_json(indent=2))

    def load_index(self) -> str:
        p = config.WIKI_DIR / "_meta" / "index.md"
        return p.read_text() if p.exists() else ""

"""Anthropic SDK wrapper with prompt-cache control on system prompts."""
import anthropic
import config

_client_singleton: anthropic.Anthropic | None = None


def _client() -> anthropic.Anthropic:
    global _client_singleton
    if _client_singleton is None:
        _client_singleton = anthropic.Anthropic(api_key=config.ANTHROPIC_API_KEY)
    return _client_singleton


def call_claude(system: str, user: str, max_tokens: int | None = None) -> str:
    resp = _client().messages.create(
        model=config.CLAUDE_MODEL,
        max_tokens=max_tokens or config.CLAUDE_MAX_TOKENS,
        system=[{"type": "text", "text": system, "cache_control": {"type": "ephemeral"}}],
        messages=[{"role": "user", "content": user}],
    )
    return resp.content[0].text

  {"type": "SUPERSEDE",  "old_id": "<existing-id>", "new_statement": "...", "reason": "..."}
  {"type": "RETIRE",     "id": "<existing-id>", "reason": "..."}
  {"type": "MERGE",      "ids": ["<id-a>","<id-b>"], "merged_statement": "...", "reason": "..."}

RULES:
1. A concept is ONE atomic, testable proposition. Not vague definitions.
2. UPDATE = same idea, different phrasing. Preserve id.
3. SUPERSEDE = the claim materially changed (number corrected, scope narrowed).
4. RETIRE = wiki no longer asserts the concept.
5. MERGE = two existing concepts collapsed into one.
6. ADD only for genuinely new propositions.
7. Objective content only. No "the user," no "you," no preferences.
8. If no changes needed: {"ops": []}.

Be conservative: prefer UPDATE over SUPERSEDE; prefer no-op over guessing.

```python
"""sync_page: LLM-diff a wiki page against its concepts.json sidecar and apply ops."""
import json
import re
from datetime import datetime, timezone

from brain2.llm.claude import call_claude
from brain2.llm.prompts import load as load_prompt
from brain2.ids import concept_id
from brain2.models import Concept, ConceptsFile
from brain2.store.base import Store


def parse_diff_response(raw: str) -> list[dict]:
    s = raw.strip()
    s = re.sub(r"^```(?:json)?\s*", "", s)
    s = re.sub(r"\s*```$", "", s)
    return json.loads(s).get("ops", [])


def _topic_from_page_path(page_path: str) -> str:
    fname = page_path.replace("\\", "/").split("/")[-1]
    if not fname.endswith(".md"):
        raise ValueError(f"page_path must end with .md: {page_path!r}")
    return fname[:-3]


def apply_ops(cf: ConceptsFile, ops: list[dict], now: datetime | None = None) -> dict:
    now = now or datetime.now(timezone.utc)
    by_id = {c.id: c for c in cf.concepts}
    added, updated, superseded, retired, merged = [], [], [], [], []

    for op in ops:
        t = op["type"]
        if t == "ADD":
            cid = concept_id(cf.topic, op["statement"])
            if cid in by_id:
                continue
            c = Concept(id=cid, topic=cf.topic, statement=op["statement"], source_page=cf.topic, created_at=now)
            cf.concepts.append(c); by_id[cid] = c; added.append(cid)
        elif t == "UPDATE":
            tgt = by_id.get(op["id"])
            if tgt is None: continue
            tgt.statement = op["new_statement"]; updated.append(tgt.id)
        elif t == "SUPERSEDE":
            old = by_id.get(op["old_id"])
            if old is None: continue
            old.status = "superseded"
            cid = concept_id(cf.topic, op["new_statement"])
            new_c = Concept(id=cid, topic=cf.topic, statement=op["new_statement"],
                            source_page=cf.topic, created_at=now, supersedes_id=old.id)
            cf.concepts.append(new_c); by_id[cid] = new_c; superseded.append(old.id)
        elif t == "RETIRE":
            tgt = by_id.get(op["id"])
            if tgt is None: continue
            tgt.status = "retired"; retired.append(tgt.id)
        elif t == "MERGE":
            for src in op["ids"]:
                s = by_id.get(src)
                if s is not None: s.status = "retired"
            cid = concept_id(cf.topic, op["merged_statement"])
            new_c = Concept(id=cid, topic=cf.topic, statement=op["merged_statement"],
                            source_page=cf.topic, created_at=now)
            cf.concepts.append(new_c); by_id[cid] = new_c; merged.append(cid)

    return {"added": added, "updated": updated, "superseded": superseded, "retired": retired, "merged": merged}


def sync_page(store: Store, page_path: str) -> dict:
    topic = _topic_from_page_path(page_path)
    wiki_text = store.load_wiki_md(topic)
    if wiki_text is None:
        raise FileNotFoundError(f"wiki page not found for topic {topic!r}")
    current_hash = store.wiki_md_hash(topic)

    cf = store.load_concepts_file(topic)
    if cf is None:
        cf = ConceptsFile(topic=topic, source_page_path=f"wiki/{topic}/{topic}.md")

    if cf.wiki_content_hash == current_hash:
        return {"changed": False, "added": [], "updated": [], "superseded": [], "retired": [], "merged": []}

    existing = [{"id": c.id, "statement": c.statement} for c in cf.concepts if c.status == "active"]
    user_msg = (
        f"<current_concepts>{json.dumps(existing, indent=2)}</current_concepts>\n"
        f"<new_wiki_text>\n{wiki_text}\n</new_wiki_text>\n"
        f"Topic slug: {topic}"
    )
    raw = call_claude(load_prompt("claude_sync_diff"), user_msg)
    ops = parse_diff_response(raw)
    summary = apply_ops(cf, ops)
    cf.wiki_content_hash = current_hash
    cf.last_synced_at = datetime.now(timezone.utc)
    store.save_concepts_file(cf)
    return {"changed": True, **summary}
```

```python
"""py-fsrs wrapper mapped to/from our FSRSState model."""
from datetime import datetime, timezone
from fsrs import Scheduler, Card, Rating, State

import config
from brain2.models import FSRSState

_scheduler = Scheduler(desired_retention=config.FSRS_REQUEST_RETENTION)
_RATING_MAP = {1: Rating.Again, 2: Rating.Hard, 3: Rating.Good, 4: Rating.Easy}


def _to_card(state: FSRSState) -> Card:
    if state.last_reviewed is None:
        return Card()
    c = Card()
    c.difficulty = state.difficulty
    c.stability = state.stability
    c.last_review = state.last_reviewed
    c.state = State.Review
    return c


def _from_card(card: Card, now: datetime) -> FSRSState:
    return FSRSState(
        difficulty=card.difficulty,
        stability=card.stability,
        last_reviewed=card.last_review or now,
        retrievability=card.get_retrievability(now) if card.last_review else 1.0,
    )


def apply_review(state: FSRSState, rating: int, now: datetime | None = None) -> FSRSState:
    now = now or datetime.now(timezone.utc)
    card = _to_card(state)
    new_card, _log = _scheduler.review_card(card, _RATING_MAP[rating], review_datetime=now)
    return _from_card(new_card, now)


def current_retrievability(state: FSRSState, now: datetime | None = None) -> float:
    now = now or datetime.now(timezone.utc)
    if state.last_reviewed is None:
        return 1.0
    return _to_card(state).get_retrievability(now)


def is_due(state: FSRSState, now: datetime | None = None) -> bool:
    return current_retrievability(state, now) < config.FSRS_RETRIEVABILITY_THRESHOLD
```

> **Note:** If `py-fsrs`'s API differs from the assumed (Scheduler, Card, Rating, State) shape, adapt the wrapper but keep `apply_review`, `current_retrievability`, `is_due` signatures stable.

```python
"""record_review: apply a rating to per-user FSRS state and persist."""
from datetime import datetime, timezone

from brain2.models import FSRSState, ReviewEvent, UserConceptState, UserStateFile
from brain2.fsrs_.scheduler import apply_review
from brain2.store.base import Store


def _topic_from_id(cid: str) -> str:
    return cid.split("/", 1)[0]


def record_review_for_concepts(store: Store, user_id: str, concept_ids: list[str], rating: int,
                                now: datetime | None = None) -> dict[str, FSRSState]:
    now = now or datetime.now(timezone.utc)
    by_topic: dict[str, list[str]] = {}
    for cid in concept_ids:
        by_topic.setdefault(_topic_from_id(cid), []).append(cid)

    out: dict[str, FSRSState] = {}
    for topic, ids in by_topic.items():
        us = store.load_user_state(user_id, topic) or UserStateFile(user_id=user_id, topic=topic)
        by_cid = {s.concept_id: s for s in us.states}
        for cid in ids:
            s = by_cid.get(cid) or UserConceptState(concept_id=cid)
            s.fsrs = apply_review(s.fsrs, rating, now=now)
            s.review_history.append(ReviewEvent(ts=now, rating=rating))
            if cid not in by_cid:
                us.states.append(s); by_cid[cid] = s
            out[cid] = s.fsrs
        store.save_user_state(us)
    return out

"""get_due_concepts: per-user retrievability query."""
from datetime import datetime, timezone

import config
from brain2.fsrs_.scheduler import current_retrievability
from brain2.models import Concept, FSRSState
from brain2.store.base import Store


def get_due_concepts(store: Store, user_id: str, limit: int = 20,
                      topic: str | None = None, now: datetime | None = None) -> list[Concept]:
    now = now or datetime.now(timezone.utc)
    topics = [topic] if topic else store.list_topics()
    candidates: list[tuple[float, Concept]] = []

    for t in topics:
        cf = store.load_concepts_file(t)
        if cf is None:
            continue
        us = store.load_user_state(user_id, t)
        state_by_id = {s.concept_id: s.fsrs for s in (us.states if us else [])}
        for c in cf.concepts:
            if c.status != "active":
                continue
            fsrs = state_by_id.get(c.id, FSRSState())
            r = current_retrievability(fsrs, now)
            if r < config.FSRS_RETRIEVABILITY_THRESHOLD:
                candidates.append((r, c))

    candidates.sort(key=lambda pair: pair[0])
    return [c for _r, c in candidates[:limit]]

```python
"""Session selection (Nugget > Chunk > none) — per user."""
from datetime import datetime, timezone

from brain2.fsrs_.due import get_due_concepts
from brain2.store.base import Store


def _reviewed_ids(store: Store, user_id: str, topic: str) -> set[str]:
    us = store.load_user_state(user_id, topic)
    return {s.concept_id for s in us.states if s.review_history} if us else set()


def _first_unreviewed_topic(store: Store, user_id: str) -> tuple[str, datetime] | None:
    best = None
    for topic in store.list_topics():
        cf = store.load_concepts_file(topic)
        if cf is None:
            continue
        reviewed = _reviewed_ids(store, user_id, topic)
        unr = [c for c in cf.concepts if c.status == "active" and c.id not in reviewed]
        if not unr:
            continue
        oldest = min(c.created_at for c in unr)
        if best is None or oldest < best[1]:
            best = (topic, oldest)
    return best


def _topic_with_most_stale(store: Store, user_id: str, now: datetime) -> tuple[str, int] | None:
    best = None
    for topic in store.list_topics():
        due = get_due_concepts(store, user_id, limit=10_000, topic=topic, now=now)
        if not due:
            continue
        if best is None or len(due) > best[1]:
            best = (topic, len(due))
    return best


def recommend_session(store: Store, user_id: str = "self", now: datetime | None = None) -> dict:
    now = now or datetime.now(timezone.utc)
    nug = _first_unreviewed_topic(store, user_id)
    if nug is not None:
        topic = nug[0]
        cf = store.load_concepts_file(topic)
        reviewed = _reviewed_ids(store, user_id, topic)
        ids = [c.id for c in cf.concepts if c.status == "active" and c.id not in reviewed]
        return {"type": "nugget", "source_page": topic, "concept_ids": ids}

    ch = _topic_with_most_stale(store, user_id, now)
    if ch is not None:
        due = get_due_concepts(store, user_id, limit=10_000, topic=ch[0], now=now)
        return {"type": "chunk", "topic": ch[0], "concept_ids": [c.id for c in due]}

    return {"type": "none", "message": "✅ All caught up. No session needed today."}


def start_nugget(store: Store, source_page: str, user_id: str = "self") -> dict:
    cf = store.load_concepts_file(source_page)
    if cf is None:
        raise ValueError(f"No concepts for topic {source_page!r}")
    reviewed = _reviewed_ids(store, user_id, source_page)
    return {"concept_ids": [c.id for c in cf.concepts if c.status == "active" and c.id not in reviewed]}


def start_chunk(store: Store, topic: str | None = None, user_id: str = "self",
                now: datetime | None = None) -> dict:
    now = now or datetime.now(timezone.utc)
    if topic is None:
        pick = _topic_with_most_stale(store, user_id, now)
        if pick is None:
            return {"concept_ids": []}
        topic = pick[0]
    due = get_due_concepts(store, user_id, limit=10_000, topic=topic, now=now)
    return {"concept_ids": [c.id for c in due]}

```python
"""generate_reading + generate_card."""
import json
import re

from brain2.llm.claude import call_claude
from brain2.llm.prompts import load as load_prompt
from brain2.models import Concept
from brain2.store.base import Store


def _concepts_for_ids(store: Store, concept_ids: list[str]) -> list[Concept]:
    by_topic: dict[str, list[str]] = {}
    for cid in concept_ids:
        by_topic.setdefault(cid.split("/", 1)[0], []).append(cid)
    out: list[Concept] = []
    for topic, ids in by_topic.items():
        cf = store.load_concepts_file(topic)
        if cf is None:
            continue
        wanted = set(ids)
        out.extend([c for c in cf.concepts if c.id in wanted])
    return out


def _strip_fences(raw: str) -> str:
    s = raw.strip()
    s = re.sub(r"^```(?:json)?\s*", "", s)
    s = re.sub(r"\s*```$", "", s)
    return s


def generate_reading(store: Store, concept_ids: list[str], style: str) -> dict:
    if style not in ("nugget", "chunk"):
        raise ValueError(f"style must be 'nugget' or 'chunk', got {style!r}")
    cs = _concepts_for_ids(store, concept_ids)
    payload = [{"id": c.id, "statement": c.statement} for c in cs]
    user = f"<concepts>{json.dumps(payload, indent=2)}</concepts>\n<style>{style}</style>"
    return {"prose": call_claude(load_prompt("claude_generate_reading"), user)}


def generate_card(store: Store, concept_ids: list[str], hints: str = "") -> dict:
    cs = _concepts_for_ids(store, concept_ids)
    payload = [{"id": c.id, "statement": c.statement} for c in cs]
    user = f"<concepts>{json.dumps(payload, indent=2)}</concepts>\n<hints>{hints}</hints>"
    raw = call_claude(load_prompt("claude_generate_card"), user)
    return json.loads(_strip_fences(raw))
```

```python
"""Wiki updater: merge unprocessed raw files into the wiki page via Claude."""
import re
from datetime import datetime, timezone

from brain2.llm.claude import call_claude
from brain2.llm.prompts import load as load_prompt
from brain2.store.base import Store


def _flip_wiki_updated(raw: str) -> str:
    return re.sub(r"^wiki_updated:\s*false\s*$", "wiki_updated: true", raw, count=1, flags=re.MULTILINE)


def _extract_summary_line(wiki_md: str) -> str:
    """First non-heading paragraph, single line, ~140 chars."""
    for line in wiki_md.splitlines():
        s = line.strip()
        if s and not s.startswith("#") and not s.startswith("<!--"):
            return (s[:140] + "…") if len(s) > 140 else s
    return ""


def _update_index(store: Store, topic: str, summary: str) -> None:
    existing = store.load_index() or "## Wiki Index\n\n| Page | Summary |\n|------|---------|\n"
    line = f"| [[{topic}]] | {summary} |"
    # Replace existing row for this topic, or append
    pattern = re.compile(rf"^\| \[\[{re.escape(topic)}\]\] \|.*$", re.MULTILINE)
    new = pattern.sub(line, existing) if pattern.search(existing) else existing.rstrip() + "\n" + line + "\n"
    store.save_index(new)


def update_wiki_for_topic(store: Store, topic: str) -> dict:
    unprocessed = store.list_unprocessed_raw(topic)
    if not unprocessed:
        return {"sources_merged": 0, "topic": topic}

    current_wiki = store.load_wiki_md(topic) or ""
    sources_xml = "\n".join(
        f'<source file="{fn}">{store.load_raw_file(topic, fn)}</source>'
        for fn in unprocessed
    )
    user_msg = (
        f"<current_wiki_page>{current_wiki or '(empty — new topic)'}</current_wiki_page>\n"
        f"<new_sources count=\"{len(unprocessed)}\">{sources_xml}</new_sources>\n"
        f"Topic slug: {topic}"
    )
    new_md = call_claude(load_prompt("claude_wiki_update"), user_msg)
    store.save_wiki_md(topic, new_md)

    for fn in unprocessed:
        raw = store.load_raw_file(topic, fn)
        store.save_raw_file(topic, fn, _flip_wiki_updated(raw))

    _update_index(store, topic, _extract_summary_line(new_md))
    ts = datetime.now(timezone.utc).isoformat()
    store.append_log(f"{ts} | wiki-update | {topic} | merged {len(unprocessed)} sources: {', '.join(unprocessed)}")
    return {"sources_merged": len(unprocessed), "topic": topic, "files": unprocessed}
```

```python
"""/rename — propagate a topic slug rename across vault.
Each step is idempotent; safe to retry from step 1 on failure."""
import re
import shutil
from datetime import datetime, timezone

import config
from brain2.store.base import Store


def _replace_wikilinks(md: str, old: str, new: str) -> str:
    return re.sub(rf"\[\[{re.escape(old)}(\|[^\]]+)?\]\]",
                  lambda m: f"[[{new}{m.group(1) or ''}]]", md)


def rename_topic(store: Store, old: str, new: str) -> dict:
    # 1. Move raw dir
    src_raw = config.RAW_DIR / old
    dst_raw = config.RAW_DIR / new
    if src_raw.exists() and not dst_raw.exists():
        shutil.move(str(src_raw), str(dst_raw))

    # 2. Move wiki dir, rename inner files
    src_wiki = config.WIKI_DIR / old
    dst_wiki = config.WIKI_DIR / new
    if src_wiki.exists() and not dst_wiki.exists():
        shutil.move(str(src_wiki), str(dst_wiki))
        for suffix in (".md", config.CONCEPTS_FILENAME_SUFFIX):
            old_inner = dst_wiki / f"{old}{suffix}"
            new_inner = dst_wiki / f"{new}{suffix}"
            if old_inner.exists() and not new_inner.exists():
                old_inner.rename(new_inner)

    # 3. Update topic: in raw frontmatter
    for f in store.list_raw_files(new):
        content = store.load_raw_file(new, f)
        store.save_raw_file(new, f, re.sub(rf"^topic:\s*{re.escape(old)}\s*$", f"topic: {new}", content, count=1, flags=re.MULTILINE))

    # 4. Update wikilinks across all wiki pages
    for topic in store.list_topics():
        md = store.load_wiki_md(topic)
        if md and f"[[{old}" in md:
            store.save_wiki_md(topic, _replace_wikilinks(md, old, new))

    # 5. Update index.md
    idx = store.load_index()
    if f"[[{old}" in idx:
        store.save_index(_replace_wikilinks(idx, old, new))

    # 6. Rename per-user state files
    for user_dir in (config.REVIEWS_DIR.iterdir() if config.REVIEWS_DIR.exists() else []):
        if not user_dir.is_dir():
            continue
        old_p = user_dir / f"{old}.json"
        new_p = user_dir / f"{new}.json"
        if old_p.exists() and not new_p.exists():
            content = old_p.read_text().replace(f'"topic": "{old}"', f'"topic": "{new}"').replace(f'"{old}/', f'"{new}/')
            new_p.write_text(content)
            old_p.unlink()

    ts = datetime.now(timezone.utc).isoformat()
    store.append_log(f"{ts} | rename | {old} → {new}")
    return {"renamed": f"{old}→{new}"}
```

"""/merge_pages — combine two wiki pages into one new page."""
import shutil
from datetime import datetime, timezone

import config
from brain2.llm.claude import call_claude
from brain2.llm.prompts import load as load_prompt
from brain2.store.base import Store
from brain2.wiki.rename import _replace_wikilinks


def merge_pages(store: Store, page_a: str, page_b: str, new_slug: str) -> dict:
    md_a = store.load_wiki_md(page_a)
    md_b = store.load_wiki_md(page_b)
    if md_a is None or md_b is None:
        raise ValueError(f"both pages must exist: {page_a!r}, {page_b!r}")

    user = (
        f'<page_a slug="{page_a}">{md_a}</page_a>\n'
        f'<page_b slug="{page_b}">{md_b}</page_b>\n'
        f"<new_slug>{new_slug}</new_slug>"
    )
    merged = call_claude(load_prompt("claude_wiki_merge"), user)
    store.save_wiki_md(new_slug, merged)

    # Delete old wiki dirs
    for p in (page_a, page_b):
        d = config.WIKI_DIR / p
        if d.exists() and p != new_slug:
            shutil.rmtree(d)

    # Update wikilinks across remaining pages
    for topic in store.list_topics():
        md = store.load_wiki_md(topic)
        if md and (f"[[{page_a}" in md or f"[[{page_b}" in md):
            md = _replace_wikilinks(md, page_a, new_slug)
            md = _replace_wikilinks(md, page_b, new_slug)
            store.save_wiki_md(topic, md)

    ts = datetime.now(timezone.utc).isoformat()
    store.append_log(f"{ts} | merge | {page_a}+{page_b} → {new_slug}")
    return {"merged_into": new_slug}

```python
"""Async task tracking. Tasks persist in .brain2/tasks.json."""
import uuid
from datetime import datetime, timezone
from typing import Any

from brain2.models import Task
from brain2.store.base import Store


def _now() -> datetime:
    return datetime.now(timezone.utc)


def create_task(store: Store, user_id: str, task_type: str, input: dict[str, Any]) -> Task:
    now = _now()
    t = Task(
        id=f"task-{uuid.uuid4().hex[:8]}",
        user_id=user_id, type=task_type, input=input,
        created_at=now, updated_at=now,
    )
    tasks = store.load_tasks()
    tasks.append(t)
    store.save_tasks(tasks)
    return t


def update_task(store: Store, task_id: str, *, status: str | None = None, progress: str | None = None,
                result: dict | None = None, error: str | None = None) -> Task:
    tasks = store.load_tasks()
    for t in tasks:
        if t.id == task_id:
            if status is not None: t.status = status
            if progress is not None: t.progress = progress
            if result is not None: t.result = result
            if error is not None: t.error = error
            t.updated_at = _now()
            store.save_tasks(tasks)
            return t
    raise ValueError(f"task {task_id!r} not found")


def get_task(store: Store, task_id: str) -> Task | None:
    for t in store.load_tasks():
        if t.id == task_id:
            return t
    return None


def list_tasks(store: Store, user_id: str | None = None, status: str | None = None,
               limit: int = 20) -> list[Task]:
    tasks = store.load_tasks()
    if user_id:
        tasks = [t for t in tasks if t.user_id == user_id]
    if status:
        tasks = [t for t in tasks if t.status == status]
    tasks.sort(key=lambda t: t.created_at, reverse=True)
    return tasks[:limit]


def mark_orphaned_on_startup(store: Store) -> int:
    """Any task left in 'running' from a previous process is marked failed."""
    tasks = store.load_tasks()
    flipped = 0
    for t in tasks:
        if t.status == "running":
            t.status = "failed"
            t.error = "interrupted by Brain2 restart"
            t.updated_at = _now()
            flipped += 1
    if flipped:
        store.save_tasks(tasks)
    return flipped


def cancel_task(store: Store, task_id: str) -> Task:
    return update_task(store, task_id, status="cancelled")
```

```python
"""Background task runner over ThreadPoolExecutor."""
import time
from concurrent.futures import ThreadPoolExecutor, Future
from typing import Any, Callable

import config
from brain2.models import Task
from brain2.store.base import Store
from brain2.tasks.tracker import create_task, update_task, get_task


class TaskRunner:
    def __init__(self, store: Store, max_workers: int | None = None):
        self._store = store
        self._executor = ThreadPoolExecutor(max_workers=max_workers or config.TASK_MAX_WORKERS)
        self._futures: dict[str, Future] = {}

    def submit(self, user_id: str, task_type: str, input: dict[str, Any],
               func: Callable[..., Any]) -> Task:
        task = create_task(self._store, user_id, task_type, input)

        def _runner():
            update_task(self._store, task.id, status="running")
            try:
                result = func(task.id, self._store, **input)
                update_task(self._store, task.id, status="done", result=result or {})
            except Exception as e:
                update_task(self._store, task.id, status="failed", error=str(e))

        self._futures[task.id] = self._executor.submit(_runner)
        return task

    def wait(self, task_id: str, timeout: float = 60.0) -> Task:
        fut = self._futures.get(task_id)
        if fut is not None:
            fut.result(timeout=timeout)
        return get_task(self._store, task_id)

    def shutdown(self) -> None:
        self._executor.shutdown(wait=False)
```

"""Pasted-text ingestion — produce a raw markdown file."""
import re
from datetime import datetime, timezone

from brain2.store.base import Store


def _slugify(text: str, max_len: int = 50) -> str:
    s = re.sub(r"[^\w\s-]", " ", text.lower())
    s = re.sub(r"\s+", "-", s.strip())
    return s[:max_len].rstrip("-") or "untitled"


def _build_frontmatter(topic: str, title: str, source_type: str = "text",
                        source_url: str | None = None, ingest_method: str = "pasted",
                        extras: dict | None = None) -> str:
    lines = [
        "---",
        f"title: {title!r}",
        f"source_type: {source_type}",
        f"date_ingested: {datetime.now(timezone.utc).date().isoformat()}",
        f"topic: {topic}",
        f"ingest_method: {ingest_method}",
        "wiki_updated: false",
    ]
    if source_url:
        lines.insert(2, f"source_url: {source_url}")
    if extras:
        for k, v in extras.items():
            lines.append(f"{k}: {v}")
    lines.append("---")
    return "\n".join(lines)


def ingest_text_to_raw(store: Store, text: str, topic: str, title: str | None = None) -> dict:
    title = title or text.split("\n", 1)[0][:80]
    slug = _slugify(title)
    date = datetime.now(timezone.utc).date().isoformat()
    filename = f"{date}_{slug}.md"
    content = _build_frontmatter(topic, title) + "\n\n## Content\n\n" + text.strip() + "\n"
    store.save_raw_file(topic, filename, content)
    return {"topic": topic, "filename": filename}
```

"""Video URL ingestion: yt-dlp + faster-whisper."""
import tempfile
from pathlib import Path

import config


def _yt_dlp_download(url: str, out_dir: str) -> str:
    """Download audio track to out_dir, return path."""
    import yt_dlp
    opts = {
        "format": "bestaudio/best",
        "outtmpl": f"{out_dir}/%(id)s.%(ext)s",
        "quiet": True,
        "noprogress": True,
    }
    with yt_dlp.YoutubeDL(opts) as ydl:
        info = ydl.extract_info(url, download=True)
        return ydl.prepare_filename(info)


def _whisper_transcribe(audio_path: str) -> tuple[str, dict]:
    """Return (transcript_text, metadata)."""
    from faster_whisper import WhisperModel
    model = WhisperModel(config.WHISPER_MODEL, device=config.WHISPER_DEVICE)
    segments, info = model.transcribe(audio_path)
    text = " ".join(seg.text.strip() for seg in segments)
    return text, {"duration": info.duration}


def download_and_transcribe(url: str) -> dict:
    with tempfile.TemporaryDirectory() as d:
        audio_path = _yt_dlp_download(url, d)
        text, meta = _whisper_transcribe(audio_path)
    return {
        "text": text,
        "source_url": url,
        "duration_seconds": int(meta.get("duration", 0)),
    }

```python
"""PDF extraction: pdfplumber → pytesseract OCR fallback."""


def _pdfplumber_extract(path: str) -> tuple[str, int]:
    import pdfplumber
    with pdfplumber.open(path) as pdf:
        pages = pdf.pages
        text = "\n\n".join((p.extract_text() or "") for p in pages)
        return text.strip(), len(pages)


def _tesseract_ocr(path: str) -> str | None:
    """Render each PDF page to an image and OCR. Returns None on no usable output."""
    try:
        import pdfplumber
        from PIL import Image
        import pytesseract
    except ImportError:
        return None
    parts: list[str] = []
    with pdfplumber.open(path) as pdf:
        for page in pdf.pages:
            img = page.to_image(resolution=200).original
            parts.append(pytesseract.image_to_string(img))
    text = "\n\n".join(p.strip() for p in parts if p.strip())
    return text or None


def extract_pdf(path: str) -> dict:
    text, n_pages = _pdfplumber_extract(path)
    if text and len(text) > 50:
        return {"text": text, "page_count": n_pages, "ocr_used": False}
    ocr = _tesseract_ocr(path)
    if not ocr:
        raise RuntimeError("PDF extraction failed (both pdfplumber and OCR empty)")
    return {"text": ocr, "page_count": n_pages, "ocr_used": True}
```

import json
import re

from brain2.llm.ollama import call_ollama
from brain2.llm.prompts import load as load_prompt
from brain2.store.base import Store


def _strip_fences(raw: str) -> str:
    s = raw.strip()
    s = re.sub(r"^```(?:json)?\s*", "", s)
    s = re.sub(r"\s*```$", "", s)

    idx = store.load_index()
    m = re.search(rf"\| \[\[{re.escape(topic)}\]\] \| ([^|]+) \|", idx)
    return m.group(1).strip() if m else ""

    user = f"<raw>{raw_text}</raw>"
    out = call_ollama(load_prompt("ollama_clean_summarise"), user)

"""End-to-end ingestion pipeline:
raw_content → classify → clean → write /raw/ → wiki_update → lint → sync_concepts."""
from brain2.concepts.sync import sync_page
from brain2.ingestion.classify import classify_against_existing, clean_and_summarise
from brain2.ingestion.text import ingest_text_to_raw
from brain2.store.base import Store
from brain2.tasks.tracker import update_task
from brain2.wiki.lint import lint_page
from brain2.wiki.updater import update_wiki_for_topic


def run_pipeline_for_text(store: Store, task_id: str, raw_content: str,
                            source_url: str | None = None,
                            ingest_method: str = "pasted",
                            extra_frontmatter: dict | None = None) -> dict:
    """Synchronous internal pipeline used by ingest_* MCP tools."""
    update_task(store, task_id, progress="classifying")
    cls = classify_against_existing(store, raw_content)
    topic = cls.get("match") or cls.get("proposed_topic_slug")
    if not topic:
        raise RuntimeError("classify returned neither match nor proposed_topic_slug")

    update_task(store, task_id, progress="cleaning")
    cleaned = clean_and_summarise(raw_content)

    update_task(store, task_id, progress="writing-raw")
    body = "## Content\n\n" + cleaned["cleaned_content"] + "\n\n## Summary\n\n" + cleaned["summary"]
    save = ingest_text_to_raw(store, body, topic=topic, title=cleaned["title"])

    update_task(store, task_id, progress="updating-wiki")
    upd = update_wiki_for_topic(store, topic)

    update_task(store, task_id, progress="linting")
    lint = lint_page(store, topic)

    update_task(store, task_id, progress="syncing-concepts")
    sync = sync_page(store, f"wiki/{topic}/{topic}.md")

    return {
        "topic": topic,
        "raw_filename": save["filename"],
        "sources_merged": upd["sources_merged"],
        "lint_issues": len(lint.get("issues", [])),
        "concepts_added": len(sync.get("added", [])),
        "concepts_updated": len(sync.get("updated", [])),
    }

```python
"""/ask query + writeback proposal lifecycle (per-user)."""
import json
import re
import uuid
from datetime import datetime, timezone

import config
from brain2.llm.claude import call_claude
from brain2.llm.prompts import load as load_prompt
from brain2.models import WritebackProposal, WritebackProposalsFile
from brain2.store.base import Store


def _strip_fences(raw: str) -> str:
    s = raw.strip()
    s = re.sub(r"^```(?:json)?\s*", "", s)
    s = re.sub(r"\s*```$", "", s)
    return s


def _build_concept_index(store: Store) -> dict[str, list[dict]]:
    return {
        t: [{"id": c.id, "statement": c.statement}
            for c in (store.load_concepts_file(t).concepts if store.load_concepts_file(t) else [])
            if c.status == "active"]
        for t in store.list_topics()
    }


def query(store: Store, question: str, user_id: str = "self") -> dict:
    index = _build_concept_index(store)
    pages = {t: (store.load_wiki_md(t) or "") for t in index.keys()}
    user = (
        f"<question>{question}</question>\n"
        f"<concept_index>{json.dumps(index, indent=2)}</concept_index>\n"
        f"<wiki_pages>{json.dumps(pages, indent=2)}</wiki_pages>"
    )
    raw = call_claude(load_prompt("claude_query_answer"), user)
    parsed = json.loads(_strip_fences(raw))
    answer = parsed["answer"]
    citations = parsed.get("citations", [])

    result = {"answer": answer, "citations": citations}

    if len(answer.split()) >= config.WRITEBACK_MIN_WORDS and len(citations) >= config.WRITEBACK_MIN_WIKI_REFS:
        sanitized_raw = call_claude(
            load_prompt("claude_sanitize_writeback"),
            f"<question>{question}</question>\n<answer>{answer}</answer>",
        )
        sanitized = json.loads(_strip_fences(sanitized_raw))["sanitized"]
        prop = WritebackProposal(
            id=f"wb-{uuid.uuid4().hex[:8]}", user_id=user_id,
            question=question, answer=answer, citations=citations,
            target_page=citations[0], sanitized_content=sanitized,
            created_at=datetime.now(timezone.utc),
        )
        wb = store.load_writebacks(user_id)
        wb.proposals.append(prop)
        store.save_writebacks(user_id, wb)
        result["writeback_proposal_id"] = prop.id

    return result


def accept_writeback(store: Store, proposal_id: str, user_id: str = "self") -> dict:
    wb = store.load_writebacks(user_id)
    prop = next((p for p in wb.proposals if p.id == proposal_id), None)
    if prop is None:
        raise ValueError(f"no proposal {proposal_id!r} for user {user_id!r}")
    if prop.status != "pending":
        raise ValueError(f"proposal {proposal_id!r} already {prop.status}")

    existing = store.load_wiki_md(prop.target_page) or f"# {prop.target_page}\n"
    store.save_wiki_md(prop.target_page, existing.rstrip() + "\n\n" + prop.sanitized_content.rstrip() + "\n")
    prop.status = "accepted"
    store.save_writebacks(user_id, wb)
    return {"written_to_page": prop.target_page}
```

```python
"""/search — lightweight substring + frequency scoring across wiki pages and concept statements."""
import re

from brain2.store.base import Store


def _tokenize(s: str) -> list[str]:
    return re.findall(r"\w+", s.lower())


def _score(haystack: str, query_tokens: list[str]) -> int:
    text = haystack.lower()
    score = 0
    for tok in query_tokens:
        score += text.count(tok)
    return score


def _snippet(text: str, tok: str, window: int = 60) -> str:
    idx = text.lower().find(tok.lower())
    if idx < 0:
        return ""
    start = max(0, idx - window)
    end = min(len(text), idx + len(tok) + window)
    return ("…" if start > 0 else "") + text[start:end].replace("\n", " ") + ("…" if end < len(text) else "")


def search(store: Store, query: str) -> list[dict]:
    tokens = _tokenize(query)
    if not tokens:
        return []
    out = []
    for topic in store.list_topics():
        md = store.load_wiki_md(topic) or ""
        cf = store.load_concepts_file(topic)
        concept_text = "\n".join(c.statement for c in (cf.concepts if cf else []) if c.status == "active")
        haystack = md + "\n" + concept_text
        s = _score(haystack, tokens)
        if s == 0:
            continue
        snippets = [_snippet(haystack, t) for t in tokens]
        out.append({"topic": topic, "score": s, "snippets": [x for x in snippets if x]})
    out.sort(key=lambda r: r["score"], reverse=True)
    return out
```

"""/status — overview of wiki + user + tasks + writebacks."""
from datetime import datetime, timezone

from brain2.fsrs_.scheduler import current_retrievability
from brain2.models import FSRSState
from brain2.store.base import Store


def status(store: Store, user_id: str = "self") -> dict:
    now = datetime.now(timezone.utc)
    topics = store.list_topics()
    total = 0
    last_sync: datetime | None = None
    for t in topics:
        cf = store.load_concepts_file(t)
        if cf is None:
            continue
        total += sum(1 for c in cf.concepts if c.status == "active")
        if cf.last_synced_at and (last_sync is None or cf.last_synced_at > last_sync):
            last_sync = cf.last_synced_at

    due = 0
    unreviewed = 0
    last_review: datetime | None = None
    for t in topics:
        cf = store.load_concepts_file(t)
        if cf is None:
            continue
        us = store.load_user_state(user_id, t)
        state_by_id = {s.concept_id: s for s in (us.states if us else [])}
        for c in cf.concepts:
            if c.status != "active":
                continue
            ucs = state_by_id.get(c.id)
            if ucs is None or not ucs.review_history:
                unreviewed += 1
                continue
            if current_retrievability(ucs.fsrs, now) < 0.85:
                due += 1
            last = ucs.review_history[-1].ts
            if last_review is None or last > last_review:
                last_review = last

    tasks = store.load_tasks()
    wb = store.load_writebacks(user_id).proposals
    return {
        "wiki": {
            "topic_count": len(topics),
            "total_concepts": total,
            "last_sync_at": last_sync.isoformat() if last_sync else None,
        },
        "user": {
            "due_concepts": due,
            "unreviewed_concepts": unreviewed,
            "last_review_at": last_review.isoformat() if last_review else None,
        },
        "tasks": {
            "pending": sum(1 for t in tasks if t.status == "pending"),
            "running": sum(1 for t in tasks if t.status == "running"),
            "failed_recent": sum(1 for t in tasks if t.status == "failed"),
        },
        "pending_writebacks": sum(1 for p in wb if p.status == "pending"),
    }
```

"""Manual concept ops: add / update / supersede / retire / merge."""
from datetime import datetime, timezone

from brain2.ids import concept_id
from brain2.models import Concept, ConceptsFile
from brain2.store.base import Store


def _load_or_create(store: Store, topic: str) -> ConceptsFile:
    cf = store.load_concepts_file(topic)
    return cf if cf else ConceptsFile(topic=topic, source_page_path=f"wiki/{topic}/{topic}.md")


def _find(cf: ConceptsFile, cid: str) -> Concept:
    target = next((c for c in cf.concepts if c.id == cid), None)
    if target is None:
        raise ValueError(f"concept {cid!r} not found")
    return target


def add_concept(store: Store, topic: str, statement: str) -> Concept:
    cf = _load_or_create(store, topic)
    cid = concept_id(topic, statement)
    if any(c.id == cid for c in cf.concepts):
        raise ValueError(f"concept {cid!r} already exists (same statement)")
    c = Concept(id=cid, topic=topic, statement=statement, source_page=topic,
                created_at=datetime.now(timezone.utc))
    cf.concepts.append(c)
    store.save_concepts_file(cf)
    return c


def update_concept(store: Store, cid: str, new_statement: str) -> Concept:
    topic = cid.split("/", 1)[0]
    cf = _load_or_create(store, topic)
    tgt = _find(cf, cid)
    tgt.statement = new_statement
    store.save_concepts_file(cf)
    return tgt


def supersede_concept(store: Store, old_id: str, new_statement: str) -> dict:
    topic = old_id.split("/", 1)[0]
    cf = _load_or_create(store, topic)
    old = _find(cf, old_id)
    old.status = "superseded"
    new_c = Concept(id=concept_id(topic, new_statement), topic=topic, statement=new_statement,
                    source_page=topic, created_at=datetime.now(timezone.utc), supersedes_id=old_id)
    cf.concepts.append(new_c)
    store.save_concepts_file(cf)
    return {"old": old, "new": new_c}


def retire_concept(store: Store, cid: str, reason: str) -> Concept:
    topic = cid.split("/", 1)[0]
    cf = _load_or_create(store, topic)
    tgt = _find(cf, cid)
    tgt.status = "retired"
    store.save_concepts_file(cf)
    return tgt


def merge_concepts(store: Store, ids: list[str], merged_statement: str) -> dict:
    if not ids:
        raise ValueError("must merge at least one concept")
    topic = ids[0].split("/", 1)[0]
    if any(i.split("/", 1)[0] != topic for i in ids):
        raise ValueError("all ids must share the same topic")
    cf = _load_or_create(store, topic)
    retired = []
    for i in ids:
        tgt = _find(cf, i)
        tgt.status = "retired"
        retired.append(i)
    new_c = Concept(id=concept_id(topic, merged_statement), topic=topic, statement=merged_statement,
                    source_page=topic, created_at=datetime.now(timezone.utc))
    cf.concepts.append(new_c)
    store.save_concepts_file(cf)
    return {"retired": retired, "new": new_c}
```

```python
"""Thin httpx client over the brain2-api REST surface. No LLM, no business logic."""
import httpx
import config


class Brain2Client:
    def __init__(self, base_url: str | None = None, timeout: float = 120.0):
        self._base = (base_url or config.BRAIN2_API_URL).rstrip("/")
        self._timeout = timeout

    def _get(self, path: str, **params) -> object:
        r = httpx.get(f"{self._base}{path}", params=params, timeout=self._timeout)
        r.raise_for_status()
        return r.json()

    def _post(self, path: str, **body) -> object:
        r = httpx.post(f"{self._base}{path}", json=body, timeout=self._timeout)
        r.raise_for_status()
        return r.json()

    def ingest_url(self, url: str, user_id: str = "self") -> dict:
        return self._post("/ingest_url", url=url, user_id=user_id)

    def task_status(self, task_id: str) -> dict:
        return self._get(f"/tasks/{task_id}")

    def recommend_session(self, user_id: str = "self") -> dict:
        return self._get("/recommend_session", user_id=user_id)

```python
"""Telegram test-bot. Maps chat commands to brain2-api REST calls. Contains no LLM.
Session state (current concept list + position) is kept in chat_data."""
import config
from telegram import Update
from telegram.ext import Application, CommandHandler, ContextTypes

from telegram_bot.client import Brain2Client

client = Brain2Client()


def _allowed(update: Update) -> bool:
    if not config.TELEGRAM_ALLOWED_USER_IDS:
        return True
    return bool(update.effective_user) and update.effective_user.id in config.TELEGRAM_ALLOWED_USER_IDS


async def cmd_ingest(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not _allowed(update):
        return
    res = client.ingest_url(" ".join(context.args))
    await update.message.reply_text(f"Ingesting… task {res['task_id']}. Use /task {res['task_id']} to check.")


async def cmd_task(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not _allowed(update):
        return
    res = client.task_status(context.args[0])
    await update.message.reply_text(f"{res['status']} — {res.get('progress', '')}\n{res.get('result') or res.get('error') or ''}")


async def cmd_session(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not _allowed(update):
        return
    rec = client.recommend_session()
    if rec["type"] == "none":
        await update.message.reply_text(rec.get("message", "All caught up."))
        return
    context.chat_data["concept_ids"] = rec["concept_ids"]
    context.chat_data["i"] = 0
    await update.message.reply_text(
        f"{rec['type']} session: {len(rec['concept_ids'])} concepts. /next for the first card.")


async def cmd_next(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not _allowed(update):
        return
    ids = context.chat_data.get("concept_ids", [])
    i = context.chat_data.get("i", 0)
    if i >= len(ids):
        await update.message.reply_text("Session complete.")
        return
    card = client.generate_card([ids[i]])
    context.chat_data["current"] = ids[i]
    context.chat_data["back"] = card["back"]
    await update.message.reply_text(f"Q: {card['front']}\n\n/show for the answer.")


async def cmd_show(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not _allowed(update):
        return
    await update.message.reply_text(f"A: {context.chat_data.get('back', '(no active card)')}\n\nRate with /rate 1-4.")


async def cmd_rate(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not _allowed(update):
        return
    cid = context.chat_data.get("current")
    if cid:
        client.record_review([cid], int(context.args[0]))
        context.chat_data["i"] = context.chat_data.get("i", 0) + 1
    await update.message.reply_text("Recorded. /next for the next card.")


async def cmd_ask(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not _allowed(update):
        return
    res = client.ask(" ".join(context.args))
    await update.message.reply_text(res["answer"][:4000])


async def cmd_status(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not _allowed(update):
        return
    s = client.status()
    w, u = s["wiki"], s["user"]
    await update.message.reply_text(
        f"Topics {w['topic_count']} · concepts {w['total_concepts']}\n"
        f"Due {u['due_concepts']} · unreviewed {u['unreviewed_concepts']}")


def build_application() -> Application:
    app = Application.builder().token(config.TELEGRAM_BOT_TOKEN).build()
    app.add_handler(CommandHandler("ingest", cmd_ingest))
    app.add_handler(CommandHandler("task", cmd_task))
    app.add_handler(CommandHandler("session", cmd_session))
    app.add_handler(CommandHandler("next", cmd_next))
    app.add_handler(CommandHandler("show", cmd_show))
    app.add_handler(CommandHandler("rate", cmd_rate))
    app.add_handler(CommandHandler("ask", cmd_ask))
    app.add_handler(CommandHandler("status", cmd_status))
    return app


def main() -> None:
    build_application().run_polling()


if __name__ == "__main__":
    main()
```
